# 🕌 Eman AI — Islamic Assistant

Eman AI is an AI-powered Islamic learning application designed around a conversational interface and Islamic-focused features.

🌐 **Live Demo:** https://eman-ai-b85da.web.app

> **Important:** AI-generated religious answers should be verified with reliable Islamic sources and qualified scholars, especially for matters of religious ruling (fatwa).

## ✨ Features

- 🔐 Login / welcome experience
- 💬 AI conversational interface
- 📖 Quran and Islamic learning features
- 🤲 Duas section
- 📱 Responsive modern interface
- ✨ Animated and iOS-inspired UI elements
- 🔥 Firebase hosting
- 🤖 AI API integration

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Firebase
- AI API integration
